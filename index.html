Summary

Icons

How this works: a modern .icl file (or any .exe/.dll) is a Windows PE image whose resource section can hold RT_GROUP_ICON/RT_ICON entries. This page walks that resource directory directly in your browser tab and reconstructs each group as a standalone .ico — your file is never uploaded anywhere.

Why this exists: old icon libraries and custom icon DLLs are common in retro-theming, game modding, and IT asset recovery, but the only working tools for opening them are decades-old Windows desktop downloads. This page reads them directly, on any OS.

Troubleshooting

This says it's a legacy 16-bit NE file

Windows 3.x-era 16-bit icon libraries use a completely different "NE" executable format from modern 32-/64-bit "PE" files. This tool currently reads modern PE-format .icl files, EXE files, and DLL files only.

No icon groups were found

The file is a valid PE image, but its resource section has no RT_GROUP_ICON entries — either it genuinely has no icons embedded, or the icons live in an unusual resource layout this tool doesn't yet handle.

Does this run any code from the file?

No. This page only reads the file's resource directory as data — it never loads, executes, or runs anything from the .icl/.exe/.dll you drop in.
